SunuDiag

Comprendre le risque palustre à partir de quelques constantes cliniques.

SunuDiag est un outil pédagogique conçu pour illustrer comment un modèle statistique peut croiser température, glycémie, hémoglobine et contexte saisonnier pour estimer une probabilité de paludisme. Il s'adresse aux étudiants, agents de santé communautaire et curieux qui veulent voir un modèle de pré-diagnostic à l'œuvre — sans jamais se substituer à un examen médical.

Comment ça marche

1

Renseigner les constantes

Âge, température, glycémie, hémoglobine et saison — cinq champs, deux minutes.

2

Le modèle calcule un score

Un modèle entraîné sur des données cliniques et environnementales estime une probabilité.

3

Une orientation, pas un verdict

Le résultat classe le risque en trois niveaux et rappelle la marche à suivre.

Contexte de transmission

À propos de l'application
Objectif

Démontrer, dans un cadre pédagogique, comment un modèle de classification peut appuyer un pré-diagnostic du paludisme à partir de constantes facilement mesurables sur le terrain — utile notamment là où les tests rapides ne sont pas immédiatement accessibles.

Variables utilisées

Âge, température corporelle, glycémie, hémoglobine et saison (pluies ou sèche, un facteur connu de transmission vectorielle). Ces cinq variables ont été choisies pour leur disponibilité en consultation de premier niveau, sans examen de laboratoire avancé.

Méthode & performance

Le modèle est un classifieur supervisé entraîné sur un jeu de données clinique simplifié. Il obtient une AUC de 0.66 sur l'échantillon de test — une performance modeste, à visée pédagogique, qui traduit surtout la difficulté à distinguer le paludisme d'autres fièvres à partir de si peu de variables.

Limites

SunuDiag ne réalise ni test biologique ni examen clinique. Il n'intègre pas de symptômes clés (frissons, courbatures, antécédents de voyage) ni de test de diagnostic rapide. Le score doit être lu comme une indication statistique, jamais comme une confirmation ou une exclusion du paludisme.
